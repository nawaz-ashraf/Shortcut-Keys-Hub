# Shortcut Keys Hub

A premium, offline-first Flutter app for mastering keyboard shortcuts across Windows, macOS, Microsoft Office, VS Code, Chrome, AutoCAD, Tally, and Photoshop.

## ✨ Highlights
- Beautiful neumorphism + glassmorphism UI
- Light/Dark themes with animated transitions
- Offline JSON shortcut packs
- Fast search, favorites, and recent history
- Quiz mode with XP + score tracking
- Interactive keyboard viewer

## 📦 Tech Stack
- Flutter (latest stable)
- Riverpod, GoRouter
- Hive (local persistence)
- flutter_animate, flutter_neumorphic_plus
- Google Fonts, Lottie

## 🚀 Getting Started
1. Ensure Flutter is installed and in your PATH.
2. Get dependencies:
   - `flutter pub get`
3. Run the app:
   - `flutter run`

## 🗂️ Assets
Shortcut data lives in `assets/data/` as JSON files.

> Note: Lottie files are included as placeholders and can be replaced with premium animations.

## 🔧 Configuration
- Theme and favorites are stored locally using Hive.
- The app works fully offline after installation.

## ✅ Features
- Categories for Windows, macOS, Excel, Word, PowerPoint, Tally, AutoCAD, VS Code, Chrome, Photoshop
- Animated cards and interactive keycaps
- Search by category, shortcut, or function
- Favorites + bookmarks
- Recently viewed shortcuts
- Daily productivity tips
- Quiz mode with XP and score
- Settings screen with reset actions

## 📝 App Icon Concept
Keyboard key style with neon glow and premium productivity branding.
